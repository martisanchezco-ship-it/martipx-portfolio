# Martí PX — Portafolio

Sitio web estático para presentar el trabajo audiovisual, creativo y profesional de Martí PX.

## Publicar en GitHub Pages

1. Crea una cuenta en GitHub si todavía no tienes una.
2. Abre el repositorio de este proyecto.
3. Pulsa **Settings → Pages**.
4. En **Source**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/`.
6. Pulsa **Save** y espera a que GitHub Pages genere la URL.

La web usa archivos HTML, CSS y JavaScript locales, por lo que no necesita una compilación ni dependencias.

## Localmente

Desde la raíz del proyecto puedes abrir `index.html` directamente o ejecutar:

```bash
python3 -m http.server 8000
```

Después abre `http://localhost:8000` en el navegador.
